粗略地说, 模形式 (modular form) 是定义在上半复平面 `"Im"(tau) gt 0` 的复变函数, 且满足特定的变换公式和全纯条件.

基本概念

模群与模形式

模群 (modular group) 定义为全体行列式为 1 的 2 阶整系数矩阵群: `SL_2(ZZ) := { [a, b; c, d]: a, b, c, d in ZZ, a d - b c = 1 }`. 它在复球面 `CC uu {oo}` 上有一个群作用 (Möbius 变换): `gamma(tau) = (a tau + b)/(c tau + d)`, `quad gamma in SL_2(ZZ)`. 对任意 `gamma in SL_2(ZZ)`, `+-gamma` 给出同一个 Möbius 变换, 事实上 `+-I` 是 `SL_2(ZZ)` 的中心.

容易验证 `I(tau) = tau` 及 `(gamma_1 gamma_2)(tau) = gamma_1 (gamma_2(tau))`, 因此它确实是群作用.

可以验证 `A = [1, 1; 0, 1]` 和 `B = [0, -1; 1, 0]` 是模群 `SL_2(ZZ)` 的生成元, 相应的 Möbius 变换为 `tau ↦ tau+1` (平移变换) 和 `tau ↦ -1//tau` (反演 `tau ↦ 1//bar tau`, 然后关于 `y` 轴对称).

令 `C := B A^-1 B^-1 = [1, 0; 1, 1]`, 对 `AA n in ZZ`, 计算知 `A^n = [1, n; 0, 1]`, `quad C^n = [1, 0; n, 1]`. 对 `AA M = [a, b; c, d] in SL_2(ZZ)`, `A^n M` 相当于将 `M` 的第 2 行的 `n` 倍加到第 1 行, `C^n M` 相当于将 `M` 的第 1 行的 `n` 倍到加第 2 行. 对矩阵 `M` 反复执行两种初等变换, 由 `a d - b c = 1` 知道 `a, c` 互素, 通过辗转相除法, 最终可以将矩阵的第 1 列变为一个是 0, 另一个是 `+-1`. 通过左乘矩阵 `B` 或者 `B^-1`, 可以确保 `c = 0`, `a = 1`. 由于 `a d - b c = 1`, 此时必有 `d = 1`, 从而矩阵已经化为 `[1, b; 0, 1] = A^b`.
[群友@QED] 两个生成元给出了 `gamma(tau)` 的连分数展开.

定义上半复平面为 `cc H = { tau in CC: "Im"(tau) gt 0 }`, 证明: 模群的每个元素 `gamma` 都给出可逆映射 `cc H to cc H`.

记 `gamma = [a, b; c, d] in SL_2(ZZ)`. 显然 `tau ↦ (a tau + b)/(c tau + d)` 可逆, 逆映射由逆矩阵 `gamma^-1` 给出: `sigma ↦ (d sigma - b)/(-c sigma + a)`. 下证 `tau in cc H` 时, 有 `gamma(tau) in cc H`. 事实上 `gamma(tau)` `= ((a tau + b)(bar (c tau + d)))/|c tau + d|^2` `= (a d tau + b c bar tau + a c |tau|^2 + b d)/|c tau + d|^2`,
`"Im"gamma(tau)` `= (gamma(tau) - bar(gamma(tau)))/(2"i")` `= (tau - bar tau)/(2"i") (a d - b c)/|c tau + d|^2` `= ("Im" tau)/|c tau + d|^2`, 因此 `"Im"gamma(tau) gt 0 iff "Im"tau gt 0`.

弱模 (weakly modularity) 设 `k in ZZ`, `f: cc H to CC` 是亚纯函数 (又叫半纯函数, 除极点外处处解析), 且对 `AA tau in cc H` 成立等式 `f(tau+1) = f(tau)`, `quad f(-1//tau) = tau^k f(tau)`. 可以证明, 对一切 `gamma = [a, b; c, d] in SL_2(ZZ)` 和 `tau in cc H` 成立 `f(gamma(tau)) = (c tau + d)^k f(tau)`. 称这样的 `f` 为弱模, 权重为 `k`.

🚧

    一些观察:
  1. 对于权重 `k = 0` 的弱模恒有 `f @ gamma = f`, 即 `f` 在 `SL_2(ZZ)` 的作用下不变. 每个常函数都是 `k=0` 的弱模. 零函数可以看作任意权重的弱模.
  2. `k = 2` 时, 由于 `"d"(gamma(tau)) = (c tau + d)^-2 "d" tau`, 这推出 `f(gamma(tau)) "d"(gamma(tau))` `= (c tau+d)^2 f(tau) (c tau + d)^-2 "d"tau` `= f(tau) "d"tau`.
  3. 若 `f` 为弱模, 令 `gamma = -I` 有 `f = (-1)^k f`, 这指出奇数权重的弱模恒为零.
  4. 两个 `k` 权重的弱模的线性组合仍是 `k` 权重的弱模; 这说明弱模实际上构成 `CC` 上的线性空间. 权重为 `k, l` 的两个弱模相乘得到一个权重为 `k+l` 的弱模.
  5. `c tau + d` 在上半平面没有零点与极点, 因此 `f @ gamma` 与 `f` 有相同的零点与极点.

模形式 (modular form) 是指在 `cc H uu {oo}` 全纯[注]的弱模. 权重为 `k` 的模形式的集合记作 `cc M_k(SL_2(ZZ))`, 这是 `CC` 上的线性空间. 权重为 `k, l` 的两个模形式相乘得到一个权重为 `k+l` 的模形式. 我们记 `cc M(SL_2(ZZ)) = O+_(k in ZZ) cc M_k(SL_2(ZZ))`, 这是一个分次环 (graded ring), 其中的一般元素 `f in cc M(SL_2(ZZ))` 可以写为有限个不同权重的模形式之和. 分次环的概念可以类比于多项式环 `CC[x]`.

考虑映射 `tau ↦ q := "e"^(2 pi"i"tau)`, 它将 `cc H uu {oo}` 映为单位圆盘 `D`, 其中 `oo` 映到原点. 由于 `"e"^(2 pi "i"tau)` 以 1 为周期, 而弱模 `f` 也以 1 为周期, 因此存在函数 `g: D to CC` 使得 `f(tau) = g(q) = g("e"^(2 pi"i"tau))`. 要验证 `f(tau)` 在 `oo` 处全纯, 只需验证 `g(q)` 在原点全纯, 换言之 `g(q)` 在原点的 Laurent 级数只有 `n ge 0` 部分: `g(q) = sum_(n ge 0) a_n q^n`. 又, `q to 0 iff "Im"tau to oo`, 要验证 `f(tau)` 在 `oo` 处全纯, 只需验证 `lim_("Im"tau to oo) |f(tau)| lt oo` 即可.
注意到 `g(q)` 正好是 `f(tau)` 的 Fourier 展开, 我们也称它为 `f` 的 `q` 级数. 模形式的 Fourier 展开是很常用的操作, 后面还会见到许多.

尖点形式 (cusp form) 是指 `q` 级数的常数项为零的模形式. 换言之, 一个模形式是尖点形式当且仅当 `lim_("Im"tau to oo) f(tau) = 0`. (我们把无穷远点 `oo` 叫做尖点). 尖点形式在模形式理论中具有特殊地位.
权重为 `k` 的尖点形式的集合记作 `cc S_k(SL_2(ZZ))`, 它是 `cc M_k(SL_2(ZZ))` 的线性子空间. 分次环 `cc S(SL_2(ZZ)) = O+_(k in ZZ) cc S_k(SL_2(ZZ))` 是 `cc M(SL_2(ZZ))` 的理想.

例子

考虑 Eisenstein 级数, 其中 `m, n` 是不全为零的整数: `G_k(tau) = sum_(m,n){::}' 1/(m tau + n)^k`, `quad tau in cc H`. 当 `k` 是 `ge 4` 的偶数时, 级数绝对收敛, 且在 `cc H` 上内闭一致收敛, 因此在 `cc H` 上是全纯的. 计算验证 `G_k(tau)` 是权重为 `k` 的模形式, 并求它的 `q` 级数.

  1. 任取 `gamma = [a, b; c, d] in SL_2(ZZ)` 有 `G_k(gamma(tau))` `= sum_(m,n){::}' (c tau + d)^k/(m (a tau+b)+n (c tau+d))^k` `= sum_(m,n){::}' (c tau + d)^k/((a m + c n) tau + (b m + d n))^k`. (`ast`) 当有序对 `(m, n)` 取遍 `L' := ZZ^2 - {(0, 0)}` 时, `(a m + c n, b m + d n) = (m, n) [a, b; c, d]` 也取遍同一集合. 这是因为 `gamma, gamma^-1` 都是整数矩阵, 因此给出 `ZZ^2` 到自身的双射. 又因矩阵可逆, 所以 `(a m + c n, b m + d n) = (0, 0)` 当且仅当 `(m, n) = (0, 0)`, 因此该矩阵给出 `L'` 到自身的双射. 总之由 (`ast`) 式得到 `G_k(gamma(tau)) = (c tau + d)^k G_k(gamma)`.
  2. 为验证 `G_k` 是模形式, 还需证 `lim_("Im"tau to oo) |G_k(tau)| lt oo`. 由于 `G_k` 以 1 为周期, 只需取定常数 `B gt 0`, 然后证明 `G_k` 在如下区域有界即可: `Omega = {tau in cc H: 0 le "Re"(tau) le 1, "Im"(tau) ge B}`. 这是一个关于 `y` 轴对称, 向北无限延伸的窄条区域. 令 `C = min{B, 1}`, 下证 `|m tau + n| ge C max{m, n}`, `quad AA tau in Omega`, `AA (m, n) in L'`. 事实上若 `m le n`, 显然 `|m tau + n| ge n ge C n`; 若 `n le m`, 则 `|m tau + n| ge |m "Im"(tau)| ge B m ge C m`. 因此在 `Omega` 上, `|G_k(tau)| le sum_(m,n){::}' 1/|m tau + n|^k` `le sum_(m,n){::}' 1/(C max{m,n})^k` `lt oo`.
  3. 最后求 `G_k` 的 `q` 级数, 即 Fourier 展开. 我们从余切函数的展式出发: `pi cot pi tau = 1/tau + sum_(n ge 1) (1/(tau + n) + 1/(tau - n))` `= sum_(n in ZZ) 1/(tau + n)`. 另一方面 `pi cot pi tau` `= pi "i" ("e"^(pi"i" tau) + "e"^(-pi"i" tau))/("e"^(pi"i" tau) - "e"^(-pi"i" tau))` `==^(q = exp(2pi"i"tau)) pi "i" (q + 1)/(q - 1)` `= pi "i" (1 - 2/(1-q))` `= pi "i" (1 - 2 sum_(n ge 0) q^n)`. 以上两式右侧对 `tau` 求 `k-1` 阶导数, 其中 `"d" q^n = n q^(n-1) * q * (2 pi "i") "d"tau = 2pi"i" n q^n "d"tau`, 得到 `(-1)^(k-1) (k-1)! sum_(n in ZZ) 1/(tau + n)^k` `= -(2 pi "i")^k sum_(n ge 1) n^(k-1) q^n`, 即 `sum_(n in ZZ) 1/(m tau + n)^k` `= (-2pi"i")^k/(k-1)! sum_(n ge 1) n^(k-1) q^(m n)`. 利用 `k` 是 `ge 4` 的偶数, 有 `G_k(tau) = 2 sum_(n ge 1) 1/n^k + 2 sum_(m ge 1) sum_(n in ZZ) 1/(m tau + n)^k`
    `= 2 zeta(k) + 2 (2pi"i")^k/(k-1)! sum_(m ge 1) sum_(n ge 1) n^(k-1) q^(m n)`
    `= 2 zeta(k) + 2 (2pi"i")^k/(k-1)! sum_(n ge 1) sigma_(k-1)(n) q^n`.     其中系数是因子求和函数: `sigma_(k-1)(n) = sum_(m | n) m^(k-1)`. 模形式就这样和数论函数联系在一起.

`E_k(tau) := G_k(tau) // 2 zeta(k)` 称为标准化的 Eisenstein 级数 (常数项为 1). 因为 `k` 是偶数, 利用 `zeta` 函数的公式 `zeta(k) = -1/2 B_k/k! (2pi"i")^k` 可知, `E_k` 的系数全为有理数: `E_k(tau) = 1 - (2 k)/B_k sum_(n ge 1) sigma_(k-1)(n) q^n`, `quad B_k` 是 Bernoulli 数. 假设已知 `E_8 = E_4^2`, 代入上式有 `1 - 16/B_8 sum_(n ge 1) sigma_7(n) q^n` `= (1 - 8/B_4 sum_(n ge 1) sigma_3(n) q^n)^2`
`= 1 - 16/B_4 sum_(n ge 1) sigma_3(n) q^n + 64/B_4^2 sum_(n ge 2) sum_(m=1)^(n-1) sigma_3(m) sigma_3(n-m) q^n`. 再代入 `B_8 = B_4 = -1//30` 化简, 比较等号两边的 `q^n` 系数得 `sigma_7(n) = sigma_3(n) + 120 sum_(m=1)^(n-1) sigma_3(m) sigma_3(n-m)`.

  1. 关于尖点形式的例子, 先考虑两个模形式 `g_2(tau) = 60 G_4(tau)`, `quad g_3(tau) = 140 G_6(tau)`. 则判别式函数 `Delta: cc H to CC` 是权重为 12 的尖点形式, 定义为 `Delta = g_2^3 - 27 g_3^2 = 0 + (2pi)^12 q + cdots`.
  2. 后面会证明 `Delta` 在 `cc H` 上没有零点, 于是模函数 (又称模不变量) `j = (12 g_2)^3 // Delta` `= ((2pi)^12 + cdots)/((2pi)^12 q + cdots)` `= 1/q + cdots` 在 `cc H` 上全纯, 是一个权重为 0 的弱模, 换言之它在 `SL_2(ZZ)` 的作用下不变. 无穷远点是 `j` 的一阶极点, 留数为 1.
  3. 一些特殊值 (其中 `omega = "e"^(2pi"i"//3)`). `g_2(omega) = 0`, `quad g_3(omega) != 0`, `quad j(omega) = 0`;
    `g_3("i") = 0`, `quad g_2("i") != 0`, `quad j("i") = 12^3`.
  1. 我们计算 `Delta` 的 `q` 级数的前两项. 因为 `Delta = (60 G_4)^3 - 27 (140 G_6)^2`
    `= 60^3 (a_0 + a_1 q + sum_(n ge 2) a_n q^n)^3 - 27 * 140^2 (b_0 + b_1 q + sum_(n ge 2) b_n q^n)^2`,     故常数项为 `60^3 * (2 zeta(4))^3 - 27 * 140^2 * (2 zeta(6))^2` `= 0`, 一次项系数为 `60^3 * 3 a_0^2 a_1 - 27 * 140^2 * 2 b_0 b_1`
    `= 60^3 * 3 * (2 zeta(4))^2 * 2 (2pi"i")^4//3! - 27 * 140^2 * 2 * 2 zeta(6) * 2(2pi"i")^6//5!`
    `= (2pi)^12`.
