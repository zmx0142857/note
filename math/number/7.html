梅森素数

梅森素数 (Mersenne prime) [OEIS] 梅森素数是指形如 `M_p = 2^p - 1` 的素数, 这是人类目前已知的最大的一类素数. 若 `p = a b`, 则 `2^(a b) - 1` 可以因式分解. 因此 `2^p - 1` 是素数的前提条件是 `p` 为一素数. 前几个梅森素数的 `p` 值是 2, 3, 5, 7, 13, 17, 19, 31, 61, 89, 107, 127... 晚年的 Euler 在双目失明的情况下通过心算验证 `M_31 = 2147483647` 为素数.

Fermat 数 [OEIS] 考虑形如 `2^n + 1` 的素数. 事实上, 若 `n = a b`, `b` 是 `ge 3` 的奇数, 则 `2^n+1` 可以因式分解. 故 `2^n+1` 为素数的必要条件是 `n` 为 `2` 的幂. Fermat 曾经考虑 `F_n = 2^(2^n)+1`, 当 `n = 1, 2, 3, 4` 时, 它们的确为素数; 然而 `F_5 = 4294967297 = 641 xx 6700417` 是合数, 并且人们猜想 `n ge 5` 时 `F_n` 不是素数.

完全数 (perfect number) 是指满足方程 `sigma(n) = 2n` 的正整数. 其中 `sigma(n)` 表示 `n` 的所有正因子之和. 前几个完全数是 6, 28, 496, 8128, 33550336... 它们正好是偶数. 奇完全数是否存在仍是一个未解之谜.

梅森素数与偶完全数的一一对应 若 `M_p` 为梅森素数, 则相应的三角形数 `M_p(M_p+1)//2` 是完全数. 反之, 偶完全数必然具有这种形式.

  1. [古希腊, Euclid] 考虑 `2^(p-1) * (2^p-1)` 的全体正因子 `1, 2, cdots, 2^(p-1)`,
    `M_p, 2 M_p, cdots, 2^(p-1) M_p`.     求和即得结论.
  2. [Leonhard Euler] 下证偶完全数必然形如 `M_p(M_p+1)//2`. 设这个偶完全数是 `2^a b`, 其中 `a` 是正整数, `b` 是奇数. 由于 `sigma` 是积性函数, 有 `2^(a+1) b` `= sigma(2^a b)` `= sigma(2^a) sigma(b)` `= (2^(a+1) - 1) sigma(b)`. 记 `n = a+1`, 则 `2^n b = (2^n - 1) sigma(b)`. 这指出 `2^n - 1` 整除 `b`, 且 `2^n` 整除 `sigma(b)`. 设 `sigma(b) = 2^n c` 则 `b = (2^n - 1) c`. 假如 `c gt 1`, 显然 `2^n - 1` 也大于 `1`, 则 `b` 至少有三个不同因子 `1, c, b`, 于是 `sigma(b) ge 1 + c + b` `= 1 + c + (2^n - 1) c` `= 1 + 2^n c` `= 1 + sigma(b)`, 矛盾. 因此 `c = 1`, 即 `b = 2^n - 1`, `sigma(b) = 2^n`. 这又推出 `b` 是素数.

设 `p` 为奇素数, 则 `2^p - 1` 的所有因子都形如 `2n p+1`, `n` 是正整数.

由于两个形如 `2n p + 1` 的数相乘, 结果仍为同一形式, 我们只需对素数作出证明. 令 `q` 是 `2^p - 1` 的素因子, 则 `q` 是奇素数. 由费马小定理, `q | 2^(q-1) - 1`. 利用公式 `gcd(2^a - 1, 2^b - 1) = 2^(gcd(a,b)) - 1`, 我们有 `2^(gcd(p, q-1)) - 1` `ge q gt 1`, 即 `gcd(p, q-1) gt 1`, 即 `p | q-1`. 又 `q-1` 是偶数, 所以存在正整数 `n` 使得 `q = 2n p + 1`.

Lucas-Lehmer 算法 用于验证 `M_p` 是否为梅森素数. 设 `p` 是奇素数, `M_p = 2^p - 1`. 令 `r_1 = 4`, `r_n = (r_(n-1)^2 - 2) mod M_p`, (取最小非负剩余) 则 `M_p` 是素数当且仅当 `r_(p-1) = 0`. 

# 该程序在个人电脑上验证第 27 个梅森素数 2**44497-1 用时两分钟
# 截至 2026 年, 人类已发现 52 个梅森素数
def test_mersenne(p):
    if p == 2:
        return True
    mp = 2**p-1
    r = 4
    for i in range(p-2):
        r = pow(r, 2, mp)
        r = (r-2) % mp
    return r == 0

Sierpiński 数与 Riesel 数 [bilibili@无限理论]
我们已经知道, 数列 `2^n +- 1` 中或多或少存在着一些素数. 现在考虑数列 `k 2^n +- 1`, `k` 为正奇数. 如果 `AA n ge 1`, `k 2^n + 1` 都不是素数, 则称 `k` 为 Sierpiński 数. 将加号换成减号类似可定义 Riesel 数. 若一个数同时是 Sierpiński 数和 Riesel 数, 则称它为 Brier 数. 三种数都是存在的, 下面是已知的最小实例 (尚未证明最小性): Sierpiński 数: 78557, `quad` Riesel 数: 509203,
Brier 数: 3316923598096294713661.

筛法

用 Eratosthenes 筛法求 100 以内的素数个数.

考虑 `sqrt 100 = 10` 以内的全体素数 2, 3, 5, 7. 对于 `10 lt n le 100`, 只要 `n` 与 2, 3, 5, 7 互素, 就能保证为素数. 记 `A = {1, cdots, 100}`, `P = 2 * 3 * 5 * 7`, 考查集合 `A` 中与 `P` 互素的整数个数, 称为筛函数: `S(A, P) = \#{a in A: (a, P) = 1}` `= sum_(a in A, (a,P) = 1) 1`. 在我们的例子中, 100 以内与 2, 3, 5, 7 互素的整数包括 10 到 100 的所有素数, 以及整数 1. 于是 `S(A, P) = pi(100) - pi(10) + 1`. 接下来利用容斥原理计算筛函数. 记 `A_d` 为 `A` 中所有 `d` 的倍数, 则 `|A_d| = |__100//d__|`. `S(A, P)` `= |A| - |A_2| - |A_3| - |A_5| - |A_7|`
`+ |A_(2*3)| + |A_(2*5)| + |A_(2*7)| + |A_(3*5)| + |A_(3*7)| + |A_(5*7)|`
`- |A_(2*3*5)| - |A_(2*3*7)| - |A_(2*5*7)| - |A_(3*5*7)|` `+ |A_(2*3*5*7)|`
`= 22`. 因此 `pi(100) = S(A, P) + pi(10) - 1 = 22 + 4 - 1 = 25`.

使用容斥原理求筛函数 设 `A` 为有限个整数的集合, `A_d` 为 `A` 中所有 `d` 的倍数. 又正整数 `P` 的所有素因子为 `p_1, cdots, p_s`, 那么根据容斥原理, `S(A, P) := sum_(a in A, (a,P) = 1) 1` `= sum_(r=0)^s (-1)^r sum_(i_1 lt cdots lt i_r) |A_(p_(i_1) cdots p_(i_r))|`. 使用上一章的 Möbius 函数, 结论简化为 `S(A, P) = sum_(d | P) mu(d) |A_d|`. 特别当 `A = {1, cdots, n}`, `P = n` 时, 得到 Euler 函数的表达式 `varphi(n) = sum_(d | n) mu(d) n//d` `= n prod_(p | n) sum_(p^a | n) mu(p^a)//p^a` `= n prod_(p | n) (1 - 1//p)`.

利用公式 `sum_(d | P) mu(d) = { 1, if P = 1; 0, if P gt 1 :}` 有 `sum_(a in A, (a,P) = 1) 1` `= sum_(a in A) sum_(d | (a,P)) mu(d)` `= sum_(d | P) mu(d) sum_(a in A, d | a) 1` `= sum_(d | P) mu(d) |A_d|`.

粗略估算, 以 `le a` 的素数去筛 `n` 以内的正整数时, 每个素数 `p` 大约筛掉 `1//p` 的选项, 因此通过筛选的数大约有这么多: `n prod_(p le a) (1-1//p)`.

    筛法求 `pi(n)` 用前 `a` 个素数去筛 `x` 以内的整数, 考虑筛函数 `varphi(x, a) := \#{ n le x: gcd(n, p_1 cdots p_a) = 1}`.
  1. 递推公式 `varphi(x, a) = varphi(x, a-1) - varphi(x//p_a, a-1)`.
  2. Legendre 等式 `pi(x) = varphi(x, a) + a - 1`, 其中 `a = pi(sqrt x)`.
  3. Lehmer 公式 `pi(x) = varphi(x, a) + a - 1 - P_2`, 其中 `a = pi(root 3 x)`. `P_2` 是区间 `(a, x]` 中通过筛选的合数的数量, 这些合数必定拥有两个素因子, 且最小素因子大于 `a`. 事实上 `P_2 = sum_(root 3 x lt p le sqrt x) (pi(x//p) - pi(p) + 1)`, `quad p` 为素数.
    4. 实测 Legendre 公式在 `10^8` 量级就会超过 python 的递归深度，但 Lehmer 不会.
  1. `x` 以内的整数要与前 `a` 个素数都互素, 首先要与前 `a-1` 个素数互素. 然后扣除掉漏网之鱼, 即那些与前 `a-1` 个素数互素, 但满足 `p_a | n` 的整数 `n`. 这当且仅当 `n//p_a` 与前 `a-1` 个素数互素.
  2. 这是因为 `x` 以内的合数最小素因子不超过 `sqrt x`. 换言之只要一个大于 `sqrt x` 的数通过了筛选, 它必为素数.
  3. `x` 以内的合数, 若它的素因子个数 `ge 3` (按重数计算), 则它的最小素因子不超过 `root 3 x`. 换言之一个大于 `root 3 x` 的数如果通过筛选, 它要么是素数, 要么是一个拥有两个因子的合数, 且最小素因子大于 `root 3 x`, 小于等于 `sqrt x`. 记这个合数为 `p q`, 两个素因子满足 `p le q le x//p`. 于是因子 `q` 的可能取法有 `pi(x//p) - pi(p) + 1` 种, 求和就得到 `P_2` 表达式.

素数定理

关于素数分布的一个重要结论是素数定理. Gauss 曾注意到, 在自然数 `n` 附近, 素数出现的频率约为 `1//ln n`. 于是他猜想, 对于充分大的实数 `x`, `x` 以内的素数大约有 `int_2^x dt/(ln t)` 这么多. 记 `le x` 的素数个数为 `pi(x)`, 上述积分记为 `"Li"(x)`, 则素数定理表述为 `pi(x) ~ "Li"(x)`, `quad x to oo`. 或者等价地, `pi(x) ~ x/(ln x)`, `quad x to oo`. 素数定理的证明比较复杂, 在下节我们先证较弱的结论 `pi(x) = Theta(x//ln x)`. 换言之, `x` 充分大时, 存在正的常数 `c_1, c_2` 使 `c_1 x/(ln x) le pi(x) le c_2 x/(ln x)`. 此即著名的 Chebyshev 不等式. 而素数定理的完整证明留到下一章.

我们证明 `"Li"(x) ~ x//ln x`. 由洛必达法则 `lim_(x to oo) ("Li"(x))/(x // ln x)` `= (1//ln x)/((ln x-1)//ln^2 x)` `= (ln x)/(ln x - 1)` `= 1`.

由素数定理推出 `p_n ~ n ln n`, `p_n` 是第 `n` 个素数.

[群友@zz] 由 `pi(x) ~ x/(ln x)` 取对数得 `ln pi(x) ~ ln x - ln ln x`. 于是利用 `n = pi(p_n)` 有 `p_n/(n ln n)` `= p_n/(pi(p_n)) * 1/ln(pi(p_n))` `~ ln p_n * 1/(ln p_n - ln ln p_n)` `~ 1`.

素数之比在 `RR^+` 中稠密.

[知乎@用户pKD90B] 任取 `alpha gt 0`, 令正数列 `alpha_j to alpha` `(j ge 2)`, 并定义 `m_j := |__j // ln j__|`, `quad n_j := |__j alpha_j//ln j__|`, 下证 `lim_(j to oo) p_(n_j)//p_(m_j) = alpha`. 由于 `p_n ~ n ln n`, 即证 `(n_j ln n_j)/(m_j ln m_j) to alpha`. 事实上, 由 `(j/(ln j) - 1) ln(j/(ln j) - 1)` `lt m_j ln m_j` `le j/(ln j)(ln j - ln ln j)` 知道, `m_j ln m_j ~ j`. 类似地, 由 `((j alpha_j)/(ln j) - 1) ln ((j alpha_j)/(ln j) - 1)` `lt n_j ln n_j` `le (j alpha_j)/(ln j) (ln j + ln alpha_j - ln ln j)` 知道, `n_j ln n_j ~ j alpha_j`.

Chebyshev 不等式

年龄不等式 [群友@Rei] 对任意实数 `x, y` 有 `floor(x + y) - floor(x) - floor(y) in {0, 1}`,
特别 `floor(2x) - 2 floor(x) in {0, 1}`. 如果把 `x` 看作出生时刻, `x + y` 看作当前时刻, 该不等式可以解释为: 今年 - (出生年份 + 年龄) = 0 或 1.

利用不等式 `floor(z) le z lt floor(z)+1`, `floor(x+y) - floor(x) - floor(y)` `lt (x+y) + (1-x) + (1-y)` `= 2`,
`floor(x+y) - floor(x) - floor(y)` `gt (x+y-1)-x-y` `= -1`.

    组合中项的素因子估计 设 `n` 为正整数, `N = (2n;n)`, `v_p(N)` 是素因子 `p` 在 `N` 中的次数. 则
  1. `2^n le 4^n//2n le N lt 4^n`;
  2. `v_p(N) le floor(ln(2n)//ln p)`, 换言之 `p^(v_p(N)) le 2n`;
  3. 若 `p gt sqrt(2n)`, 则 `v_p(N) le 1`;
  4. 若 `n lt p lt 2n`, 则 `v_p(N) = 1`; 于是 `prod_(n lt p lt 2n) p le N lt 4^n`;
  5. 若 `2n//3 lt p le n`, 则 `v_p(N) = 0`.
  1. 先证 `2^n le 4^n//2n`, 即 `2n le 2^n`. `n = 1` 时显然成立, `n gt 1` 时利用归纳假设, `2^n = 2^(n-1) + 2^(n-1) ge 2(n-1) + 2(n-1) ge 2n`. 剩下的部分, 只需注意 `4^n = (1+1)^(2n) = 2 + sum_(0 lt k lt 2n) (2n;k)`, 就有 `4^n//2n le N lt 4^n`.
  2. 记 `r = floor(ln(2n)//ln p)`, 则 `p^r le 2n lt p^(r+1)`. 利用第一章 `v_p(n!)` 的公式和年龄不等式有 `v_p(N) = v_p((2n)!) - 2 v_p(n!)` `= sum_(k=1)^r (floor((2n)/p^k) - 2 floor(n/p^k))` `le r`.
  3. 这是 2. 的推论.
  4. 这是因为每个 `n lt p lt 2n` 都整除 `N = ((2n)!)/(n!^2)`.
  5. 观察 `N = ((2n)!)/(n!^2)`, 如果 `2n//3 lt p le n`, 这样的 `p` 在分母恰好出现 `2` 次, 在分子出现 `lt 3` 次, 从而只能出现 `2` 次.
    Bertrand-Chebyshev 定理 [知乎@Zephyr, 数学天书中的证明]
  1. 对任意正整数 `n` 有 `pi(n) lt pi(2n)`, 换言之存在素数 `p` 满足 `n lt p le 2n`. 当 `n ge 2` 时, `2n` 不可能是素数, 不等式严格成立.
  2. 由 1. 立即得到较松的估计: `pi(2^n) ge n`, `p_n le 2^n`.
  1. 先证 `n` 以内的素数乘积上界: `prod_(p le n) p le 4^(n-1)`. `n le 2` 时直接验证成立. `n ge 3` 时, 只需考虑 `n` 是奇素数的情形. 设 `n = 2m+1`, 若结论对一切 `le 2m` 的正整数成立, 则 `prod_(p le 2m+1) p` `= prod_(p le m+1) p prod_(m+1 lt p le 2m+1) p` `le 4^m (2m+1;m)` `= 4^m ((2m;m) + (2m;m-1))` `le 4^m (1+1)^(2m)` `= 4^(2m)`. 故结论成立. 注意把 `n` 换成 `ge 1` 的实数, 不等式仍成立.
  2. `n ge 5` 时有 `2 lt sqrt(2n) lt 2n//3`, 我们估算 `N = (2n;n) = prod_(p le 2n) p^(v_p(N))` 的上界. 由引理, 对于 `p in [2, sqrt(2n)]`, 有 `p^(v_p(N)) le 2n`; 对于 `p in (2n//3, n]`, 有 `v_p(N) = 0`; 对于其它的 `p le 2n`, 有 `v_p(N) le 1`. 于是 `N le (2n)^(sqrt(2n)-1) prod_(p in (sqrt(2n),2n//3] uu (n, 2n]) p`. 假设不存在素数 `p in (n, 2n]`, 由 1. 有 `2n * N le (2n)^(sqrt(2n)) prod_(p in (sqrt(2n), 2n//3]) p` `le (2n)^(sqrt(2n)) 4^(2n//3)`. 但引理告诉我们 `2n * N ge 4^n`, 结合上式得到 `4^(n//3) le (2n)^(sqrt(2n))`, 即 `sqrt(2n) le 3 op(log_2)(2n)`, 这推出 `n le 426`. 但我们可以直接验证 Bertrand 结论对 `n lt 500` 成立, 例如, 下面相邻两项素数的比值小于 2: 2, 3, 5, 7, 13, 23, 43, 83, 163, 317, 631. 因此假设不正确, 证毕.

Chebyshev 估计 对任意正整数 `n` 有 `pi(2n) ge n // log_2(2n)`,
`pi(2n) - pi(n) lt 2n // log_2 n`.

记 `N = (2n;n)`. 利用组合中项估计, `2^n le N = prod_(p le 2n) p^(v_p(N))` `le (2n)^(pi(2n))`,
`n^(pi(2n) - pi(n)) le prod_(n lt p lt 2n) p le N lt 4^n`, 分别取对数即得结论.

Chebyshev 不等式 记 `pi(x)` 是不超过 `x` 的素数个数, `p_n` 为第 `n` 个素数. 我们有 `1/3 * x/(log_2 x)` `lt pi(x)` `lt 6 * x/(log_2 x)`, `quad AA x ge 2`,
`1/6 * n log_2 n` `lt p_n` `lt 8 * n log_2 n`, `quad AA n ge 2`.

    应用 Chebyshev 估计证 `pi(x)` 的上下界.
  1. `2 le x lt 6` 时直接验证左半不等式成立. `x ge 6` 时, 取 `n = floor(x//2)`, 此时成立 `2n le x lt 3n`, 因此 `pi(x) log_2 x ge pi(2n) log_2(2n)` `ge n gt x//3`. 这证明了左半不等式.
  2. 当 `n = 2^k` 时, `(pi(2^(k+1)) - pi(2^k)) k lt 2^(k+1)`, 又显然 `pi(2^(k+1)) le 2^k`, 两式相加得 `(k+1)pi(2^(k+1)) - k pi(2^k) lt 3 * 2^k`. 记 `h = ceil(log_2 x)`, 令 `k` 从 0 到 `h-1` 求和有 `h pi(2^h) lt 3 * 2^h`, 于是 `pi(x) le pi(2^h)` `lt 3 * 2^h//h` `lt 3 * (2 x)/(log_2 x)`. 这证明了右半不等式.
    再来证 `p_n` 的上下界.
  1. 在 `pi(x)` 的估计中代入 `x = p_n`. 注意 `pi(p_n) = n` 和 `p_n gt n`, 有 `n lt 6 p_n/(log_2 p_n)` `lt 6 p_n/(log_2 n)`, 这证明了左半不等式.
  2. `n = 2` 时直接验证右半不等式成立. `n ge 3` 时 `p_n` 为奇素数. 在不等式 `pi(2m) ge m // log_2 (2m)` 中取 `2m = p_n + 1`, 得 `n ln(p_n+1) ge (p_n+1)/2 * ln 2`. (`ast`) 整理得 `ln(p_n+1) le ln(2n//ln 2) + ln ln(p_n+1)`. 注意 `n ge 3 gt 2//ln 2`, 并利用不等式 `ln x lt x//2` (`x gt 0`), 有 `ln(p_n+1) lt 2 ln n + 1/2 ln(p_n+1)`. 上式结合 (`ast`) 式有 `(p_n+1)/(2n // ln 2)` `le ln(p_n+1)` `lt 4 ln n`. 这证明了右半不等式.

Chebyshev 函数

    Chebyshev 函数 两个 Chebyshev 函数定义为
  1. `vartheta(x) = sum_(p le x) ln p`, 其中 `p` 为素数;
  2. `psi(x) = sum_(p^a le x) ln p`, 其中 `p` 为素数, `a` 为正整数.
    3. 若定义 Mangoldt 函数为 `Lambda(n) = { ln p, if n = p^a; 0, "otherwise" :}`, 则 `psi(x) = sum_(n le x) Lambda(n)`.

Mangoldt 函数的和函数是对数函数: `sum_(d | n) Lambda(d) = ln n`.

设 `p` 在 `n` 中的次数为 `a_p`, 利用算术基本定理, 左边等于 `sum_(p^a | n) ln p` `= sum_(p | n) a_p ln p` `= ln(prod_(p | n) p^(a_p))` `= ln n`.

`x ge 1` 时, `sum_(n le x) psi(x // n) = ln(|__x__|!)`.

由定义, 左边等于 `sum_(n le x) sum_(k le x//n) Lambda(k)` `= sum_(n le x) sum_(n k le x) Lambda(k)` `==^(n k = m) sum_(m le x) sum_(n | m) Lambda(m/n)` `= sum_(m le x) ln m` 等于右边.

数论函数的分部求和公式 设 `r(n)` 是数论函数, `R(x) = sum_(n le x) r(n)`, `a le b` 是实数, `f in C^1[a, b]`, 则 `sum_(a lt n le b) r(n) f(n)` `= [f(x) R(x)]_a^b - int_a^b R(x) f'(x) dx`.

由 Stieltjes 分部积分显然成立. 注意, 当前 `R` 的定义是右连续的, 如果端点约定改为 `R(x) = sum_(n lt x) r(n)`, 则 `R` 变为左连续, 求和范围也要相应改为 `a le n lt b`.

比较初等的证明. 先设 `a, b` 为整数, 将积分拆成分段求和: `int_a^b R(x) f'(x) dx`
`= sum_(a lt n le b) int_(n-1)^n R(n-1) f'(x) dx`
`= sum_(a lt n le b) R(n-1) (f(n) - f(n-1))`
`= [f(n)R(n)]_a^b - sum_(a lt n le b) f(n) (R(n) - R(n-1))`
`= [f(n)R(n)]_a^b - sum_(a lt n le b) f(n) r(n)`. 倒数第二个等号使用了通常的分部求和公式 (Abel 变换).
如果 `a, b` 不是整数, 记 `A = floor(a)`, `B = floor(b)`, 考虑等价的 `A lt n le B` 上的求和, 只需证等号右边等于 `[f(x) R(x)]_A^B - int_A^B R(x) f'(x) dx`. 在 `[A, a]` 和 `[B, b]` 上 `R(x)` 分别为常数, 于是 `int_a^b R(x) f'(x) dx`
`= int_A^B R(x) f'(x) dx - int_A^a + int_B^b`
`= int_A^B R(x) f'(x) dx - [f(x)R(x)]_A^a + [f(x)R(x)]_B^b`
`= int_A^B R(x) f'(x) dx - [f(x)R(x)]_A^B + [f(x)R(x)]_a^b`.

利用单位阶跃函数有 `R(x) = sum_(n ge 1) r(n) H(x-n)`. (不是 `R_0` 吗??) 又记 `delta` 为单位脉冲函数, 则 `f ast delta = f`, `H' = delta`. `sum_(a lt n le b) r(n) f(n)`
`= sum_(a lt n le b) r(n) int_(-oo)^oo delta(x-n) f(x) dx`
`= int_a^b sum_(n ge 1) r(n) delta(x-n) f(x) dx`
`= [sum_(n ge 1) r(n) H(x-n) f(x)]_a^b` `- int_a^b sum_(n ge 1) r(n) H(x-n) f'(x) dx`
`= [f(x)R(x)]_a^b - int_a^b R(x) f'(x) dx`.

    Chebyshev 函数除以 `ln x` 后是 `pi(x)` 的良好替代, 事实上
  1. `pi(x) = (vartheta(x))/ln x + int_2^x (vartheta(t))/(t ln^2 t) dt`;
  2. `0 le psi(x) - vartheta(x) le sqrt x ln x`.
  1. 第一个 Chebyshev 函数 `vartheta(x) = sum_(p le x) ln p` `= sum_(n le x) [n = p] ln n`. 取 `1 lt a lt 2`, 利用分部求和有 `pi(x) = sum_(a lt p le x) 1` `= sum_(a lt n le x) [n = p] ln n * 1/(ln n)` `= [(vartheta(n))/(ln n)]_a^x + int_a^x (vartheta(t))/(t ln^2 t) dt` `= (vartheta(x))/(ln x) + int_2^x (vartheta(t))/(t ln^2 t) dt`.
  2. 第二个 Chebyshev 函数 `psi(x) = sum_(m ge 1) sum_(p^m le x) ln p` `= sum_(m ge 1) vartheta(x^(1//m))`. 作差得到 `0 le psi(x) - vartheta(x)` `= sum_(m ge 2) sum_(p^m le x) ln p`. 观察上式, 对固定的 `p`, 若 `p^m le x lt p^(m+1)`, 则 `ln p` 在和式中共出现 `m-1` 次, 对和式的贡献为 `(m-1) ln p le ln x`. 但 `x` 以内满足 `p^2 le x` 的素数不会超过 `sqrt x` 个, 于是上式的一个上界是 `sqrt x ln x`. 我们得到 `0 le psi(x) - vartheta(x) le sqrt x ln x`.
    上述定理推出 `lim_(x to oo) (pi(x) ln x - vartheta(x))/x = 0`,
    `lim_(x to oo) (psi(x) - vartheta(x))/x = 0`.     于是有
  1. Chebyshev 估计 `pi(x) = Theta(x//ln x)` `iff vartheta(x) = Theta(x)` `iff psi(x) = Theta(x)`. 第一个命题是 Chebyshev 不等式的推论, 因此三个命题均成立.
  2. 素数定理的等价命题: `pi(x) ~ x // ln x` `iff vartheta(x) ~ x` `iff psi(x) ~ x`. 要证素数定理, 只需证明其中一个等价命题.
[deepseek] 只证第一个极限. 由前一个定理, `(pi(x) ln x - vartheta(x))/x` `= (ln x)/x int_2^x (vartheta(t))/(t ln^2 t) dt` `:= (ln x)/x I(x)`. 我们在证 Chebyshev 不等式的第一部分时曾经证明了 `sum_(m lt p lt 2m) ln p le ln (2m;m) lt m ln 4`, 即 `vartheta(2m) - vartheta(m) lt m ln 4`. 现在取正整数 `n` 满足 `2^(n-1) le x lt 2^n`, 于是 `vartheta(x) le vartheta(2^n)` `= sum_(k=1)^n (vartheta(2^k) - vartheta(2^(k-1)))` `le sum_(k=1)^n 2^(k-1) ln 4` `le 2^n ln 4` `le 2 x ln 4`. 因此存在常数 `c` 使得对一切 `x ge 2` 有 `vartheta(x) le c x`. 将这个结果代入积分得 `I(x) le c int_2^x dt/(ln^2 t)`. 其中 `int_2^(sqrt x) dt/(ln^2 t)` `le int_2^(sqrt x) dt/(ln^2 2)` `le (sqrt x)/(ln^2 2)`,
`int_(sqrt x)^x dt/(ln^2 t)` `le int_(sqrt x)^x dt/(ln^2 sqrt x)` `le (4x)/(ln^2 x)`. 综上 `I(x) le c ((sqrt x)/(ln^2 2) + (4x)/(ln^2 x))`, 故 `lim_(x to oo) (ln x)/x I(x) = 0`.
也可以通过分部积分 `int_2^x dt/(ln^2 t)` `= [-t/ln t]_2^x + int_2^x dt/ln t` `= 2/ln 2 - x/ln x + "Li"(x)`. 因为 `"Li"(x) ~ x/ln x`, 所以 `"Li"(x) = x/ln x + o(x/ln x)`. 综上 `I(x) le c (2/ln 2 + o(x/ln x))`, 故 `lim_(x to +oo) (ln x)/x I(x) = 0`.
