`zeta` 函数的解析延拓

我们已经知道 zeta 函数的定义是 `zeta(s) = sum_(n ge 1) 1/n^s` `("Re"(s) gt 1)`. 在积性数论函数那一章, 通过自然数的唯一因子分解, 得到 Euler 乘积公式, 它是连接 zeta 函数与素数的桥梁: `zeta(s) = prod_p 1/(1 - p^-s)`. 上式还可以这样直观理解: 设 `p` 为素数, 则 `(1 - p^-s) zeta(s) = sum n^-s - sum (p n)^-s`. (`ast`) 换言之乘以 `(1-p^-s)` 的效果是从级数中扣除所有 `p` 的倍数. 再设 `q` 为另一素数, 则 `(1-q^-s) (1-p^-s) zeta(s) = sum n^-s - sum (p n)^-s - sum (q n)^-s + sum (p q n)^-s`. 上式的效果是从级数中扣除所有 `p` 或 `q` 的倍数. `p q` 的倍数在第 2, 3 项中被重复扣除了, 因此在第 4 项补回来. 这一思路推广至无穷, 则级数除第一项外的全部项都被消去, 即得到乘积公式.
为了扩大 `zeta(s)` 的定义域, 考虑交错级数 (Dirichlet eta 函数): `eta(s) := sum_(n ge 1) (-1)^(n-1)/n^s`, `quad "Re"(s) gt 0 and s != 1`. 利用 `(ast)` 式显然有 `eta(s) = (1-2^-s) zeta(s) - 2^-s zeta(s)`, 于是 `zeta(s) = eta(s)//(1 - 2^(1-s))`. 这稍微扩大了定义域, 但仍不能令人满意. 为了将 zeta 函数的定义域扩大到除了 `s=1` 外的整个复平面, 我们需要惊人的注意力, 注意到下面的函数方程:

`zeta` 函数的函数方程 `zeta(1-s) = 2^(1-s) pi^-s cos{:(pi s)/2:} Gamma(s) zeta(s)`, 换元 `s ↦ 1-s` 得到 `zeta(s) = 2^s pi^(s-1) sin{:(pi s)/2:} Gamma(1-s) zeta(1-s)`. 如果令 `xi(s) = (s (s-1))/2 pi^(-s//2) Gamma(s/2) zeta(s)`, 则 `xi` 是整函数, 上述函数方程可写为对称形式: `xi(s) = xi(1-s)`.

方程的等价性: 利用 Legendre 倍元公式和余元公式, `Gamma(s) = 2^(s-1) pi^(-1/2) Gamma(s/2) Gamma((1+s)/2)` `= (2^(s-1) pi^(1/2) Gamma(s/2))/(cos{:(s pi)/2:} Gamma((1-s)/2)`. 代入第一个函数方程的右边得 `zeta(1-s)` `= pi^(1/2 - s) (Gamma(s/2))/(Gamma((1-s)/2)) zeta(s)`, 即 `(zeta(1-s) pi^(-(1-s)//2) Gamma((1-s)/2))/(zeta(s) pi^(-s//2) Gamma(s/2)) = 1`.

    为证 `xi(s) = xi(1-s)`, 引入级数 `theta(x) = sum_(n in ZZ) exp(-pi n^2 x)`, `quad x gt 0`.
  1. 先证 `theta(1//x) = sqrt x theta(x)`. 函数 `exp(-pi u^2)` 的 Fourier 变换是其自身, 由伸缩变换, `f(u) = exp(-pi u^2//x)` 的 Fourier 变换是 `hat(f)(v) = sqrt x exp(-pi v^2 x)`. 代入 Poisson 求和公式 `sum f(n) = sum hat(f)(n)` 即得结论.
  2. 由 Gamma 函数的定义, `n^-s pi^(-s//2) Gamma(s/2)` `= n^-s pi^(-s//2) int_0^oo t^(s//2-1) "e"^-t dt` `= 2 int_0^oo x^(s-1) "e"^(-pi n^2 x^2) dx`. 对 `n` 求和, 积分与求和换序, 并利用 `theta(x)` 的函数方程, 得 `2/(s(s-1)) xi(s)`
    `= int_0^oo x^(s-1) (theta(x^2)-1) dx`
    `= int_1^oo y^(-s-1) (theta(y^-2)-1) dy + int_1^oo x^(s-1) (theta(x^2)-1) dx`
    `= int_1^oo (x^(-s) + x^(s-1)) (theta(x^2)-1) dx` `+ int_1^oo x^-s - x^(-s-1) dx`
    `= int_1^oo (x^(-s) + x^(s-1)) (theta(x^2)-1) dx` `- 1/s - 1/(1-s)`.     最终的结果关于 `s, 1-s` 是对称的, 故 `xi(s) = xi(1-s)`. 上式第一项的积分视为 `s` 的函数在复平面上解析 (??), 因此 `xi(s)` 在复平面上解析.
  1. `lim_(s to 1) (s-1) zeta(s) = 1`.
  2. `lim_(s to 0) zeta(s) = -1/2`.
  1. 在函数方程的证明最后, 两个一阶极点 `s = 0, 1` 分别来自 `Gamma` 函数与 `zeta` 函数. 代入 `xi(s)` 的定义即得, `zeta` 函数在 `s = 1` 的 Laurent 展式的主项为 `1//(s-1)`, 换言之 `lim_(s to 1) (s-1)zeta(s) = 1`.
  2. 代入函数方程, `lim_(s to 0) zeta(s)` `= lim_(s to 0) 1/pi sin{:(pi s)/2:} zeta(1-s)` `= lim_(s to 0) s/2 zeta(1-s)` `= lim_(s to 1) (1-s)/2 zeta(s)` `= -1/2`.

Riemann zeta 函数在 `s in CC - {1}` 的定义如下: `zeta(s) := { eta(s)//(1-2^(1-s)), if "Re"(s) gt 0 and s != 1; 2^s pi^(s-1) sin(pi s//2) Gamma(1-s) zeta(1-s), if "Re"(s) le 0 and s != 0; -1//2, if s = 0 :}` zeta 函数解析延拓的方法不止一种, 还可以用 Euler-Maclaurin 公式进行延拓.

    zeta 函数在整数的取值 [参考这里]
  1. 对非负整数 `n` 有 `zeta(2n) = -1/2 (B_(2n))/((2n)!) (2pi"i")^(2n)`, 其中 `B_(2n)` 是 Bernoulli 数. 特别 `zeta(2) = pi^2/6`.
  2. 对非负整数 `n` 有 `zeta(-n) = -(B_(n+1)^+)/(n+1)`, 特别 `zeta(-1) = -1/12`, 并且当 `m` 是 `ge 2` 的偶数时 `zeta(-m) = 0`. 这是 zeta 函数的平凡零点, 平平无奇, 且都是一阶零点.
  3. `s = 1` 是 zeta 函数的一阶极点 (这个事实也可以从 zeta 函数的 Euler-Maclaurin 公式看出).
  4. 当 `m` 是 `ge 3` 的奇数时, `zeta(m)` 很有可能都是无理数, 其中 `zeta(3)` 的无理性已被证明, 称为 Apéry 常数, `zeta(5)` 的无理性也在 AI 时代被证明. 这些常数的无理性涉及到丢番图逼近, 已不在本文的讨论范围内.

zeta 函数的非平凡零点 是指它除了负偶数以外的零点. 根据 `Gamma` 函数的性质 (没有零点, 全体极点为 `{-n}_(n ge 0)`, 且都是一阶极点) 可知, `Gamma(s//2)` 除了 `s = 0` 的极点外, 其余极点与 `zeta(s)` 的平凡零点正好抵消. 因此 `zeta(s)` 的非平凡零点恰好就是 `xi(s)` 的全体零点. 根据函数方程 `xi(s) = xi(1-s)`, zeta 函数的全体非平凡零点必定关于直线 `"Re"(s) = 1//2` 对称. 又, 我们可以证明 `xi(bar s) = bar(xi(s))`, 所以这些非平凡零点也关于直线 `"Im"(s) = 0` 对称. 这引出著名的 Riemann 猜想: `zeta(s)` 的非平凡零点都落在直线 `"Re"(s) = 1//2` 上?

`zeta(s)` 的非平凡零点都落在关键带 (或临界带, critical strip) 内: `0 lt "Re"(s) lt 1`.

    由对称性, 只需证 `"Re"(s) ge 1` 时 `zeta` 函数无零点.
  1. 先证 `sigma = "Re"(s) gt 1` 时 `zeta(s) != 0`, 这只需证 `|ln zeta(s)| lt oo`. 因为 `ln zeta(s) = -sum_p ln(1-p^-s)` `= sum_p sum_(n ge 1) p^(-s k)/k`, 所以 `|ln zeta(s)|` `le sum_p sum_(k ge 1) |p^(-s k)/k|` `le sum_p sum_(k ge 1) p^(-sigma k)` `= sum_p p^-sigma/(1 - p^-sigma)` `le 1/(1 - 2^-sigma) sum_p p^-sigma` `lt oo`.
  2. 再证直线 `"Re"(s) = 1` 上面没有 `zeta` 函数的零点. 如若不然, 设 `zeta(1+"i"tau) = 0`, 则有 `lim_(sigma to 1^+) |zeta^3(sigma) zeta^4(sigma+"i"tau) zeta(sigma+2"i"tau)| = 0`. 这意味着存在实数 `sigma gt 1` 使得 `L := ln |zeta^3(sigma) zeta^4(sigma+"i"tau) zeta(sigma+2"i"tau)| lt 0`. 另一方面, `"Re"(s) gt 1` 时 `ln zeta(s) = sum_p sum_(k ge 1) p^(-s k)/k` `==^(n = p^k) sum_(n ge 2) (k Lambda(n))/(ln n) n^-s/k` `= sum_(n ge 2) (Lambda(n))/(ln n) n^-s`. 其中 `Lambda(n) := ln p [n = p^k]`. 于是 `L = ln |zeta^3(sigma) zeta^4(sigma+"i"tau) zeta(sigma+2"i"tau)|`
    `= "Re"(3 ln zeta(sigma) + 4 ln zeta(sigma+"i"tau) + zeta(sigma+2"i"tau))`
    `= sum_(n ge 2) (Lambda(n))/(ln n) n^-sigma "Re"(3 + 4 n^(-"i"tau) + n^(-2"i"tau))`.     其中 `"Re"(3 + 4 n^(-"i"tau) + n^(-2"i"tau))`
    `= 3 + 4 cos(tau ln n) + cos(2 tau ln n)`
    `= 2 + 4 cos(tau ln n) + 2 cos^2(tau ln n)`
    `= 2(1 + cos(tau ln n))^2 ge 0`.     因此 `L ge 0`, 矛盾.

zeta 函数与素数计数

带权素数计数函数定义为 `Pi(x) = sum_(p^n le x) 1/n`, 它与 `pi(x)` 的联系是 `Pi(x) = sum_(n ge 1) sum_(p le root n x) 1/n` `= sum_(n ge 1) (pi(root n x))/n`. 可以证明反演公式 `pi(x) = sum_(n ge 1) (mu(n) Pi(root n x))/n`.

将 `Pi(x)` 与 `pi(x)` 的关系式代入反演公式右边得 `sum_(n ge 1) (mu(n))/n sum_(m ge 1) (pi(root (m n) x))/m` `==^(r = m n) sum_(r ge 1) (pi(root r x))/r sum_(n | r) mu(n)` `= sum_(r ge 1) (pi(root r x))/r [r = 1]` `= pi(x)`.

带权素数计数函数与 Riemann zeta 函数 像 `pi(x)` 与 `Pi(x)` 这样不连续的函数, 常见处理手段是将它们在间断点的函数值重新定义为左右极限的平均值, 即 `pi_0(x) := (pi(x+0) + pi(x-0))/2`,
`Pi_0(x) := (Pi(x+0) + Pi(x-0))/2`. 如果引入单位阶跃函数 (Heaviside step function) `H(x) = {0, x lt 0; 1//2, x = 0; 1, x gt 0:}` 则有 `pi_0(x) = sum_p H(x-p)`,
`Pi_0(x) = sum_(n ge 1) 1/n sum_p H(x - p^n)`. 可以证明 `1/s ln zeta(s) = (cc M Pi_0)(-s)`,
`Pi_0(x) = 1/(2pi"i") int_(a-"i"oo)^(a+"i"oo) ln zeta(s) x^s ("d"s)/s`. 其中 `cc M` 为 Mellin 变换.

考虑 zeta 函数的对数 `ln zeta(s) = -sum_p ln(1-p^-s)`
`= sum_p sum_(n ge 1) p^(-s n)/n`
`= sum_(n ge 1) s/n sum_p int_(p^n)^oo x^(-s-1) dx`
`= sum_(n ge 1) s/n sum_p int_0^oo H(x - p^n) x^(-s-1) dx`
`= s int_0^oo Pi_0(x) x^(-s-1) dx`. 由 Mellin 变换的定义 `(cc M f)(s) = int_0^oo f(x) x^(s-1) dx` 有 `1/s ln zeta(s) = (cc M Pi_0)(-s)`. 而 Mellin 逆变换公式是 `(cc M^-1 F)(x) = 1/(2pi"i") int_(c-"i"oo)^(c+"i"oo) F(s) x^-s "d"s`
`==^(a=-c) 1/(2pi"i") int_(-a-"i"oo)^(-a+"i"oo) F(s) x^-s "d"s`
`==^(u=-s) -1/(2pi"i") int_(a+"i"oo)^(a-"i"oo) F(-u) x^u "d"u`
`= 1/(2pi"i") int_(a-"i"oo)^(a+"i"oo) F(-s) x^s "d"s`. 因此 `Pi_0(x) = 1/(2pi"i") int_(a-"i"oo)^(a+"i"oo) 1/s ln zeta(s) x^s "d"s`.

我们还能将更多的素数计数函数与 zeta 函数相联系, 比如上一章的 Chebyshev 函数. 为此先把前一个例子提取为引理:

Perron 公式 考虑 Dirichlet 级数 `A(s) = sum_(n ge 1) a_n/n^s`, 若它在 `"Re"(s) gt sigma` 上一致收敛, 则对任意 `a gt sigma` 成立 `sum_(n le x){::}' a_n = 1/(2pi"i") int_(a-"i"oo)^(a+"i"oo) A(s) x^s ("d"s)/s`. 记号 `'` 表示当 `x` 为整数时, 最后一项 `a_x` 要除以 2.

和前面一样, 利用积分 `int_n^oo s x^(-s-1) dx = n^-s`, 对和式 `f(x) := sum_(n le x){::}' a_n = sum_(n ge 1) a_n H(x-n)` 乘以 `s x^(-s-1)` 再逐项积分有 `s int_0^oo f(x) x^(-s-1) dx` `= sum_(n ge 1) int_0^oo a_n H(x-n) s x^(-s-1) dx` `= sum_(n ge 1) a_n int_n^oo s x^(-s-1) dx` `= sum_(n ge 1) a_n/n^s`. 这意味着 `A(s)//s = (cc M f)(-s)`. 再应用 Mellin 逆变换公式即得结论.

Chebyshev `psi` 函数的显式表达式 `psi(x) = x - (zeta'(0))/(zeta(0)) - sum_(n ge 1) x^(-2n)/(-2n) - sum_rho x^rho/rho`
`= x - ln(2pi) - 1/2 ln(1-x^-2) - sum_rho x^rho/rho`. 其中 `rho` 遍历 `zeta` 函数的非平凡零点, `-2n` 遍历平凡零点.

  1. 将 `psi(x) = sum_(n le x) Lambda(n)` 代入 Perron 公式: `psi(x) = 1/(2pi"i") int_(a-"i"oo)^(a+"i"oo) sum_(n ge 1) (Lambda(n))/n^s x^s ("d"s)/s`. (`x` 是整数怎么办??) 其中 `sum_(n ge 1) (Lambda(n))/n^s` `= sum_p sum_(m ge 1) (ln p)/p^(m s)` `= sum_p ln p p^-s/(1-p^-s)` `= sum_p "d"/("d"s) ln(1-p^-s)` `= -"d"/("d"s) ln zeta(s)` `= - (zeta'(s))/(zeta(s))`. 🚧

证明素数定理 `pi(x) ~ x//ln x` 的等价形式: `psi(x) ~ x`.

由 `psi` 的显式表达式有 `(psi(x))/x = 1 - (ln(2pi))/x - 1/(2 x) ln(1-x^-2) - sum_rho x^(rho-1)/rho`. 因此只需证 `sum_rho x^(rho-1)/rho to 0`. 🚧
