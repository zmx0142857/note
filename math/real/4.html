Lebesgue 积分的定义与性质

    Lebesgue 积分 设 `f` 是可测集 `E sube RR^n` 上的可测函数, 从特殊到一般, 逐步定义 `f` 的积分如下:
  1. 设 `f` 是非负可测简单函数, 在 `E_i` 上取值为 `c_i`. 定义它在 `E = ⨆_i E_i` 上的积分为 `int_E f(x) dx := sum_i c_i * m(E_i)`. 这里, 我们约定 `0 * oo = oo * 0 = 0`.
  2. 设 `f` 是 `E` 上的非负可测函数, 定义 `int_E f(x) dx` `:= sup_(h le f) int_E h(x) dx`. 这里 `h(x)` 是 `E` 上的非负可测简单函数, `h le f` 是指 `AA x in E, h(x) le f(x)`.
  3. 一般地, 设 `f` 是 `E` 上的可测函数, 定义 `f` 的正部与负部: `f^(+) = max(f, 0)`, `quad f^(-)= max(-f, 0)`. 从而 `f` 的正部负部都是非负函数, 且 `f = f^(+) - f^(-)`, `quad |f| = f^(+) + f^(-)`. 现在定义 `int_E f(x) dx` `:= int_E f^(+)(x) dx - int_E f^(-)(x) dx`. 上式右端两个积分都有限 (`lt oo`) 时, 就称 `f` 在 `E` 上 Lebesgue 可积, 或 `f` 是 `E` 上的可积函数, 记作 `f in L(E)` 或 `f in L^1(E)`.

积分的保序性 `f le g rArr int_E f(x) dx le int_E g(x) dx`.

  1. 先设 `f, g` 是非负可测简单函数, 且 `f` 在 `A_i` 上取值 `a_i`, `g` 在 `B_j` 上取值 `b_j`. 将定义域细分为 `E = uuu_(i,j) A_i nn B_j`. 在每一小块 `A_i nn B_j` 上, `f, g` 的值都为常数且 `f le g`, 因此 `int_E f le int_E g`.
  2. 再设 `f, g` 是非负可测函数. 任取非负可测简单函数 `h` 满足 `h le f le g`, 由于 `g` 的积分是所有 `le g` 的非负可测简单函数积分的上界, 所以 `int_E h le int_E g`. 上式两边取上确界得 `int_E f le int_E g`.
  3. 最后对一般的可测函数 `f, g`, 由 `f le g` 知道 `f^(+) le g^(+)`, `f^(-) ge g^(-)`, 于是 `int_E f` `= int_E f^(+) - int_E f^(-)` `le int_E g^(+) - int_E g^(-)` `= int_E g`.
    控制函数与可积性
  1. 若存在可积函数 `F` 满足 `|f| le F`, 则由保序性, `f` 也可积; `F` 称为 `f` 的控制函数.
  2. 特别地, 测度有限集合上的有界可测函数可积; 这只需把控制函数取为 `|f|` 的上界即可.
  3. 若 `|f|` 可积, 则 `f` 也可积, 事实上 `|int_E f| le int_E |f|`.

由于 `|f| = f^(+) + f^(-)`, 所以 `f` 可积 `iff |f|` 可积. Lebesgue 可积是一种绝对可积, 这导致一些条件收敛的广义 Riemann 积分不是 Lebesgue 可积的. 尽管如此, 不必担心! Lebesgue 积分的理论十分有用.

    积分为零的条件
  1. `f` 在 `E` 上几乎处处为零 `rArr int_E f(x) dx = 0`;
  2. `m(E) = 0` `rArr int_E f(x) dx = 0`.
    3. 对非负可测函数, 上面两个结论是易证的; 对一般可测函数使用不等式 `|int_E f| le int_E |f|` 即可.

子集上的积分 若 `f in L(E)`, `A` 是 `E` 的可测子集, 则 `f in L(A)`, 且 `int_A f(x) dx = int_E f(x) chi_A(x) dx`. 若 `f` 是非负的, 结合保序性有 `int_A f(x) dx le int_E f(x) dx`.

  1. 先设 `f` 是非负可测简单函数, 在 `E_i` 上取值为 `c_i`. 则 `g(x) := f(x) chi_A(x)` 也是非负可测简单函数, 且 `g(x) = { c_i, if x in E_i nn A; 0, if x in E \\ A :}` `int_A f(x) dx` `= sum c_i m(E_i nn A)` `= sum c_i m(E_i nn A) + sum 0 * m(E \\ A)` `= int_E g(x) dx`.
  2. 再设 `f` 是非负可测函数, 则 `int_A f(x) dx` `= sup_(h le f) int_A h(x) dx` `= sup_(h chi_A le f chi_A) int_A h(x) dx` `= sup_(h le f chi_A) int_E h(x) dx` `= int_E f(x) chi_A(x) dx`.
  3. 最后对一般的可测函数 `f`, 因为 `(f chi_A)^(+-) = f^(+-) chi_A`, 所以 `int_A f` `= int_A f^(+) - int_A f^(-)` `= int_E f^(+) chi_A - int_E f^(-) chi_A` `= int_E (f chi_A)^(+) - int_E (f chi_A)^(-)` `= int_E f chi_A`.
    积分的线性性 设 `f, g` 可积, 则 `c f`, `f + g` 也可积, 且有
  1. `int_E c f(x) dx = c int_E f(x) dx`;
  2. `int_E (f(x) + g(x)) dx = int_E f(x) dx + int_E g(x) dx`.
  1. 先设 `f, g` 是非负可测简单函数. 此时 1. 式直接由定义成立; 为证明 2. 式, 注意到 `f + g` 也是一个非负可测简单函数, 它在 `A_i nn B_j` 上的取值为 `a_i + b_j`. 于是 `int_E (f(x) + g(x)) dx`
    `= sum_(i,j) (a_i + b_j) m(A_i nn B_j)`
    `= sum_i a_i sum_j m(A_i nn B_j) + sum_j b_j sum_i m(A_i nn B_j)`
    `= sum_i a_i m(A_i) + sum_j b_j m(B_j)`
    `= int_E f(x) dx + int_E g(x) dx`.
  2. 再设 `f, g` 是非负可测函数, 且 `c ge 0`. 则由 1. 有 `int_E c f(x) dx` `= sup_(h le c f) int_E h(x) dx` `= c sup_(h le f) int_E h(x) dx` `= c int_E f(x) dx`. 由简单函数逼近定理, 存在 `E` 上的非负可测简单函数渐升列 `varphi_k uarr f`, `psi_k uarr g`, 于是 `(varphi_k + psi_k) uarr (f + g)`. 根据下一节的 Beppo Levi 定理[注], 非负渐升列的积分与极限可交换, 于是 `int_E (f + g)` `= lim_k int_E (varphi_k + psi_k)` `= lim_k (int_E varphi_k + int_E psi_k)` `= int_E f + int_E g`.
    3. [deepseek] 如果不使用 Beppo Levi 定理, 也可以这样证明: 显然任意 `h_1 le f` 和 `h_2 le g` 都满足 `h_1 + h_2 le f + g`, 所以 `int_E (f + g) ge int_E f + int_E g`. 另一方面, 对任意 `h le f + g` 和 `epsi gt 0`, 都可以构造出 `h_1 le f` 和 `h_2 le g` 满足 `int_E h le int_E h_1 + int_E h_2 + epsi`, 于是 `int_E h le int_E f + int_E g + epsi`, 取上确界, 由 `epsi` 的任意性得到 `int_E (f + g) le int_E f + int_E g`. 然而具体的构造比较繁琐复杂.

最后设 `f, g` 是一般的可测函数, 注意到左侧函数的可积性由控制函数 `|c f| = |c| |f|` 和 `|f + g| le |f| + |g|` 保证, 下面证明两个等式. 因为 `(-f)^(+) = max(-f, 0) = f^(-)`,
`(c f)^(+-) = { c (f^(+-)), c ge 0; -c (f^(∓)), c lt 0 :}`, 所以 `int_E c f` `= int_E (c f)^(+) - int_E (c f)^(-)` `= c (int_E f^(+) - int_E f^(-))` `= c int_E f`. 另一方面, 因为 `(f+g)^(+) - (f+g)^(-)` `= f + g` `= f^(+) - f^(-) + g^(+) - g^(-)`, 移项得 `(f+g)^(+) + f^(-) + g^(-) = (f+g)^(-) + f^(+) + g^(+)`. 上式左右每一项都是可积的非负可测函数, 由 2. 有 `int_E (f+g)^(+) + int_E f^(-) + int_E g^(-) = int_E (f+g)^(-) + int_E f^(+) + int_E g^(+)`. 整理即得 `int_E (f + g) = int_E f + int_E g`.

  1. 可积函数几乎处处有限 若 `int_E |f(x)| dx lt oo`, 则 `|f|` 几乎处处 `lt oo`.
  2. 积分为零的非负函数几乎处处为零 若 `int_E |f(x)| dx = 0`, 则 `|f|` 几乎处处 `= 0`.
  1. 对每个正整数 `k`, 令 `E_k = {x in E: |f(x)| gt k}`, 由保序性, `k m(E_k) = int_(E_k) k dx` `le int_(E_k) |f(x)| dx` `= int_E |f(x)| chi_(E_k)(x) dx` `le int_E |f(x)| dx` `lt oo`. 因此 `lim_(k to oo) m(E_k) = 0`. 进而 `m({ x in E: |f(x)| = +oo })` `= m(nnn_(k ge 1) E_k)` `= lim_(k to oo) m(E_k)` `= 0`.
  2. 对每个正整数 `k`, 记 `E_k = {x in E: |f(x)| gt 1//k}`, 由保序性, `1/k m(E_k)` `= int_(E_k) 1/k dx` `le int_(E_k) |f(x)| dx` `le int_E |f(x)| dx` `= 0`, 因此 `m(E_k) = 0`. 进而 `m({x in E: |f(x)| gt 0})` `= m(uuu_(k ge 1) E_k)` `le sum_(k ge 1) m(E_k)` `= 0`.
  1. 积分区域的有限可加性 若 `E` 是可测子集 `A, B` 的不交并, 则 `int_E f(x) dx = int_A f(x) dx + int_B f(x) dx`. 后面我们还会证明积分区域的可数可加性.
  2. 零测集上的函数值不影响积分 若 `f, g` 在 `E` 上几乎处处相等, 则 `int_E f(x) dx = int_E g(x) dx`.
  1. 利用 `f = f chi_A + f chi_B`, `int_E f(x) dx`
    `= int_E f(x) chi_A(x) dx + int_E f(x) chi_B(x) dx`, 由积分的线性性
    `= int_A f(x) dx + int_B f(x) dx`, 由子集上的积分.
  2. 记 `A = {x in E: f(x) = g(x)}`, `B = {x in E: f(x) != g(x)}`. 则 `E` 是 `A, B` 的不交并, 且 `m(B) = 0`. 由 1. 有 `int_E f(x) dx = int_A f(x) dx + int_B f(x) dx` `= int_A g(x) dx + int_B g(x) dx` `= int_E g(x) dx`.

控制收敛定理

本节考虑积分的极限与极限的积分的关系, 这包括递增集列上的积分与函数列的积分.

非负可测情形

递增集列与积分换序 (非负可测情形) 若 `{E_k}` 是 `RR^n` 中的递增可测集合列, `f` 是 `RR^n` 上的非负可测简单函数, 则 `int_(lim_(k to oo) E_k) f(x) dx = lim_(k to oo) int_(E_k) f(x) dx`.

设 `E = lim_(k to oo) E_k`, `f` 在 `A_i` 上取值 `a_i`. 集合极限与测度换序, 得到 `lim_(k to oo) int_(E_k) f(x) dx` `= lim_(k to oo) sum_i a_i m(A_i nn E_k)` `= sum_i a_i m(A_i nn E)` `= int_E f(x) dx`.

Beppo Levi 定理 若非负可测函数渐升列 `f_k` 有极限, 则 `int_E lim_(k to oo) f_k(x) dx = lim_(k to oo) int_E f_k(x) dx`. 等号两边可以是 `oo`.

  1. 记 `f_k to f`, 于是 `f` 也是非负可测函数, `int_E f` 有定义 (可以为有限或 `oo`). 由渐升性知 `AA k, f_k le f_(k+1) le f`, 于是由保序性 `int_E f_k le int_E f_(k+1) le int_E f`. 这说明 `lim_(k to oo) int_E f_k` 有定义 (可以为有限或 `oo`), 且 `lim_(k to oo) int_E f_k le int_E f`.
  2. 下证另一方向的不等式. 任取非负可测简单函数 `h le f` 和 `c in (0, 1)`, 则 `c h lt f`. 由于 `f_k to f`, 对固定的 `x in E` 总存在 `k` 使得 `f_k(x) ge c h(x)`. 记 `E_k = {x in E: f_k(x) ge c h(x)}`, 则 `E_k` 是递增集列, 且 `lim_(k to oo) E_k = E`. 于是 `int_E f_k` `ge int_(E_k) f_k` `ge int_(E_k) c h` `= c int_(E_k) h`. 令 `k to oo`, 由引理有 `lim_(k to oo) int_E f_k ge c int_E h`. 再令 `c to 1^(-)`, 由 `h` 的任意性可知 `lim_(k to oo) int_E f_k ge int_E f`.
    取 `c in (0, 1)` 是非常高明的, 因为如果取 `epsi gt 0` 使得 `f_k + epsi ge h`, 则当 `m(E) = oo` 时无法合理地消掉 `epsi`.
  1. Beppo Levi 定理的条件可减弱为 `f_k overset "a.e." to f`.
  2. 对于非负可测函数渐降列 `f_k overset "a.e." to f`, 如果 `f_1` 可积, 则每个 `f_k` 包括 `f` 也是可积的, 且积分与极限可换序.
  3. 对于非负可测函数而言, 递增集列与积分换序引理仍成立, 只需注意 `int_(E_k) f = int_E f chi_(E_k)`, 然后对非负渐升列 `f chi_(E_k)` 使用 Beppo Levi 定理即可.

Fatou 引理 对任意非负可测函数列 `f_k` 有 `int_E underset(k to oo)(ul lim) f_k(x) dx le underset(k to oo)(ul lim) int_E f_k(x) dx`.

记 `g_k(x) = inf_(j ge k) f_j(x)`, 从而 `g_k` 是非负可测函数渐升列, 且 `underset(k to oo)(ul lim) f_k(x) = sup_(k ge 1) g_k(x) = lim_(k to oo) g_k(x)`. 由 Beppo Levi 定理 `int_E underset(k to oo)(ul lim) f_k(x)` `= int_E lim_(k to oo) g_k(x)` `= lim_(k to oo) int_E g_k(x)` `= underset(k to oo)(ul lim) int_E g_k(x)` `le underset(k to oo)(ul lim) int_E f_k(x)`.

结论记忆: SL ≤ LS. 上楼 ≤ 楼上. 正在上楼的人, 位置低于已在楼上的人.

和 Beppo Levi 定理比较, Fatou 引理去掉了渐升的条件, 结论的极限也减弱为下极限, 且等号减弱为不等号. 有时这个不等号严格成立, 例如 `f_n = n * chi_((0, 1//n))` 满足 `f_n to 0`, 但 `int_0^1 lim f_n = 0 lt 1 = lim int_0^1 f_n`.

可积函数情形

控制收敛定理 (DCT) 设可测函数列 `f_k overset "a.e." to f`. 若 `F in L(E)`, 且几乎处处 `|f_k| le F` (称 `F` 为控制函数), 则 `f` 可积, 并且 `int_E f(x) dx = lim_(k to oo) int_E f_k(x) dx`. 事实上可以证明更强的结论 `f_k overset (L^1) to f`, 即 `lim_(k to oo) int_E |f_k(x) - f(x)| dx = 0`.

  1. 由已知 `f` 是可测函数, 且几乎处处 `|f| le F`, 因此 `f in L(E)`. 同理每个 `f_k in L(E)`.
  2. 令 `g_k = |f_k - f|`, 则 `g_k overset "a.e." to 0`, 且几乎处处 `g_k le |f_k| + |f| le 2 F`, 于是 `g_k in L(E)`.
  3. 对非负函数列 `2 F - g_k` 应用 Fatou 引理, 注意负号移出时下极限变为上极限: `int_E 2F` `= int_E lim_(k to oo) (2 F - g_k)` `le underset(k to oo)(ul lim) int_E (2 F - g_k)` `= int_E 2F - underset(k to oo)(bar lim) int_E g_k`, 即 `underset(k to oo)(bar lim) int_E g_k le 0`, 从而只能 `lim_(k to oo) int_E g_k = 0`. 这证明了第二个等式.
  4. 最后, 由下式立即推出第一个等式: `|int_E f_k - int_E f| le int_E |f_k - f| to 0`.

控制收敛定理是 Lebesgue 积分最重要的结果之一, 建议熟练掌握运用. 和 Beppo Levi 定理相比, 这里的 `f_k` 既不要求非负也不要求渐升, 只需存在一个控制函数即可. Beppo Levi 定理中非负渐升列 `f_k` 的极限 `f` 相当于是一个控制函数 (如果它可积).

若 `f_k overset (L^1) to f`, 则 `f_k overset m to f`. 根据 Riesz 定理, 存在子列 `f_(k_i) overset "a.e." to f`.

设 `f_k` 依 `L^1` 收敛到 `f`, 即 `lim_(k to oo) int_E |f_k - f| = 0`. 对 `AA epsi gt 0`, 记 `E_k(epsi) = { x in E: |f_k(x) - f(x)| ge epsi }`, 有 `epsi m(E_k(epsi))` `= int_(E_k(epsi)) epsi dx` `le int_(E_k(epsi)) |f_k(x) - f(x)| dx` `le int_E |f_k(x) - f(x)| dx`. 令 `k to oo` 有 `m(E_k(epsi)) to 0`, 故 `f_k` 依测度收敛到 `f`.

控制收敛定理要求 `f_k overset"a.e." to f`, 这一条件可以适当放宽. 下面的定理给出依测度收敛的情形, 但要求 `E = RR^n`, 且每个 `f_k` 可积.

依测度控制收敛定理* 设 `E = RR^n`, `f_k in L(E)`, 且 `f_k overset m to f`. 若存在控制函数 `F in L(E)` 使得几乎处处 `|f_k| le F`, 则 `f in L(E)` 且 `int_E f(x) dx = lim_(k to oo) int_E f_k(x) dx`.

逐项积分定理 对任意非负可测函数列 `f_k` 成立 `int_E sum_(k ge 1) f_k(x) dx = sum_(k ge 1) int_E f_k(x) dx`. 若不要求非负, 只要求 `f_k in L(E)`, 那么只需 `sum_(k ge 1) int_E |f_k(x)| dx lt oo`, 上式仍成立.

  1. 先设 `f_k` 是非负可测函数, 注意 `S_n = sum_(k=1)^n f_k` 是非负可测函数渐升列. 利用 Beppo Levi 定理和积分线性性, `"LHS" = int_E lim_(n to oo) S_n` `= lim_(n to oo) int_E S_n` `= lim_(n to oo) sum_(k=1)^n int_E f_k` `= "RHS"`. (`ast`)
  2. 若不要求非负, 我们需要保证在新的条件下, 等式仍有意义: 即积分号下的函数可积, 求和号下的级数收敛. 等号右边没有问题, 下证等号左边的级数收敛且和函数可积. 由 1. 有 `int_E sum_(k ge 1) |f_k| = sum_(k ge 1) int_E |f_k| lt oo`. 记 `F = sum_(k ge 1) |f_k| in L(E)`, 因为 `F` 可积, 所以 `F` 几乎处处有限, 因此级数 `sum_(k ge 1) f_k` 几乎处处 (绝对) 收敛, 记它的和函数为 `f`. 显然 `F` 是 `f` 的控制函数, 故 `f in L(E)`.
  3. 最后证明等式成立, 记部分和 `S_n = sum_(k=1)^n f_k`, 则 `|S_n| le F`, 由下文的控制收敛定理知 `"LHS" = int_E lim_(n to oo) S_n` `= lim_(n to oo) int_E S_n` `= lim_(n to oo) sum_(k=1)^n int_E f_k` `= "RHS"`. 读者不难注意到这就是把 (`ast`) 抄了一遍 😄

积分区域的可数可加性 设 `f in L(E)`, `E` 是可数个集合 `E_k` 的不交并, 则 `int_E f(x) dx = sum_(k ge 1) int_(E_k) f(x) dx`. 这个性质是 Riemann 积分所不具备的. 特别令 `f -= 1` 可以看到, 积分区域的可数可加性本质是测度的可数可加性.

  1. 先设 `f` 非负可测, `f * chi_(E_k)` 也是非负可测函数, 逐项积分有 `"LHS" = int_E sum_(k ge 1) f * chi_(E_k)` `= sum_(k ge 1) int_E f * chi_(E_k)` `= "RHS"`.
  2. 再考虑一般的 `f in L(E)`, 由 1. 知两级数收敛: `sum_(k ge 1) int_(E_k) f^(+-) = int_E f^(+-) lt oo`, 于是可以逐项相减: `"LHS"` `= int_E f^(+) - int_E f^(-)` `= sum_(k ge 1) (int_(E_k) f^(+) - int_(E_k) f^(-))` `= "RHS"`.

积分号下求导 设 `f(x, y)` 是定义在 `E xx (a, b)` 上的函数, 它作为 `x` 的函数在 `E` 上可积, 作为 `y` 的函数在 `(a, b)` 上可微. 如果存在导数 `del_y f` 的控制函数 `F in L(E)`: `|del_y f(x, y)| le F(x)`, `quad (x, y) in E xx (a, b)`, 那么可以进行积分号下求导: `int_E del_y f(x, y) dx = del_y int_E f(x, y) dx`.

  1. 任取 `y in (a, b)` 与实数列 `h_k to 0`, 记 `g_k(x, y) = (f(x, y + h_k) - f(x, y))/h_k`, 则 `del_y f(x, y) = lim_(k to oo) g_k(x, y)`,
    `del_y int_E f(x, y) dx = lim_(k to oo) int_E g_k(x, y) dx`.     由微分中值定理, 存在 `eta_k in (0, h_k)` 使得 `|g_k(x, y)|` `= |del_y(x, y+eta_k)|` `le F(x)`, 于是由控制收敛定理即得结论.

与 Riemann 积分相比, 不论是逐项积分还是积分号下求导的条件都大为简化, 这就是控制收敛的威力.

最后, 让我们回到本节开头的命题, 它可以推广到一般的可积函数.

递增集列与积分换序 (可积函数情形) 若 `{E_k}` 是 `RR^n` 中的递增可测集合列, `E = lim_(k to oo) E_k`. 如果 `AA k, f in L(E_k)`, 且 `lim_(k to oo) int_(E_k) |f(x)| dx` 存在, 那么 `f in L(E)`, 且 `int_E f(x) dx = lim_(k to oo) int_(E_k) f(x) dx`. 此定理可以用来计算无穷区间上的 Lebesgue 积分或有限区间上的瑕积分等. 与广义 Riemann 积分不同, 这里的方法只适用于积分绝对收敛的情形.

先对非负函数 `|f|` 使用递增集列与积分换序, `int_E |f| = lim_(k to oo) int_(E_k) |f| lt oo`, 因此 `f in L(E)`. 现在考虑 `f * chi_(E_k) to f`, 控制函数为 `|f * chi_(E_k)| le |f|`, 应用控制收敛定理即得结论.

与 Riemann 积分的比较

我们知道, Riemann 积分的几何直观是切分定义域, 将许多竖条的面积相加. 相比之下, Lebesgue 积分的几何直观则是切分值域, 将许多 (未必连续) 的横条面积相加. 按 Lebesgue 本人的话来说: 假定我欠人家许多钱, 现在要归还. 此时, 应先按照钞票面值分类, 计算每一类的总值, 最后相加, 这就是我的积分思想. 如果不管面值大小如何, 而是按顺手递出的次序来计算总数, 那就是 Riemann 积分的思想.

    Lebesgue 积分的几何直观 设 `m(E) lt oo`, `f` 是 `E` 上几乎处处有限的非负可测函数.
  1. 取严格递增数列 `{y_k}`, 满足 `y_0 = 0`, `y_(k+1) - y_k lt delta`, 又记 `E_k = { x in E: y_k le f(x) lt y_(k+1) }`. 则 `f in L(E)` 当且仅当下面的级数收敛: `sum_(k ge 0) y_k m(E_k) lt oo`. 并且 `delta to 0` 时, 级数的值趋于 `int_E f(x) dx`.
  2. `f in L(E)` 当且仅当 `sum_(n ge 0) m({ x in E: f(x) ge n }) lt oo`.
  1. 在 `E_k` 上, `y_k le f(x) lt y_(k+1)`, 由积分保序性 `y_k m(E_k) le int_(E_k) f le y_(k+1) m(E_k)`. 求和, 利用积分区域的可数可加性 `sum_(k ge 0) y_k m(E_k)` `le int_E f` `le sum_(k ge 0) y_(k+1) m(E_k)`
    `= sum_(k ge 0) (y_(k+1) - y_k) m(E_k) + sum_(k ge 0) y_k m(E_k)`
    `le delta m(E) + sum_(k ge 0) y_k m(E_k)`.     由于 `m(E) lt oo`, 上式 `delta m(E)` 有限, 故 `int_E f lt oo iff sum_(k ge 0) y_k m(E_k) lt oo`. 又显然 `delta to 0` 时二者相等.
  2. 利用 Abel 变换 `sum_(n ge 0) m({ x in E: f(x) ge n })`
    `= sum_(n ge 0) sum_(k ge n) m({ x in E: k le f(x) lt k+1 })`
    `= sum_(k ge 0) sum_(n=0)^k m({ x in E: k le f(x) lt k+1 })`
    `= sum_(k ge 0) (k+1) m({ x in E: k le f(x) lt k+1 })`
    `= sum_(k ge 0) k m({ x in E: k le f(x) lt k+1 }) + m(E)`.     取数列 `y_k = k`, 由 1. 知 `f in L(E)` 当且仅当上式的级数收敛.

回忆 Riemann 积分的相关概念: 设 `f` 是 `[a, b]` 上的有界函数, 定义它在 `x` 处的振幅为 `omega(x) := lim_(delta to 0^(+)) omega_delta(x)` `= lim_(delta to 0^(+)) sup_(y, z in B(x, delta) nn [a, b]) |f(y) - f(z)|`. 由于 `f` 有界, `omega` 是非负有界的; 且 `omega(x) = 0` 当且仅当 `f` 在 `x` 处连续. 作定义域的分割 `Delta: a = x_0 lt x_1 lt cdots lt x_m = b`,
`I_k = [x_(k-1), x_k]`, `quad ||Delta|| = max |I_k|`. 定义 Darboux 上、下积分: `M_k = sup_(x in I_k) f(x)`, `quad m_k = inf_(x in I_k) f(x)`,
`bar int_a^b f(x) dx = inf_Delta sum M_k |I_k|`,
`ul int_a^b f(x) dx = sup_Delta sum m_k |I_k|`.

关于 Riemann 可积的 Lebesgue 定理 设 `f` 是 `[a, b]` 上的有界函数, `omega(x)` 是它在 `x` 处的振幅, 则 `int_a^b omega(x) dx = bar int_a^b f(x) dx - ul int_a^b f(x) dx`, 其中左端是 Lebesgue 积分. 特别令上式两端等于零, 得到: 对于 `[a, b]` 上的有界函数, Riemann 可积 `iff` 几乎处处连续.

  1. 先证 `omega in L([a, b])`, 由于它非负有界, 只需证 `omega` 是可测函数. 对 `AA t in RR`, 要证明下面的集合可测: `H = {x in [a, b]: omega(x) lt t}`. 不妨设 `H != O/`. 任取 `x in H`, 则存在 `delta gt 0` 使得 `omega_delta(x) lt t`. 对任意 `x_1 in B(x, delta)`, 存在 `0 lt delta_1 lt delta` 使得 `B(x_1, delta_1) sube B(x, delta)`, 故 `omega_(delta_1)(x_1) le omega_delta(x) lt t`. 因此 `x_1 in H`. 这证明了 `B(x, delta) sube H`, 因此 `H` 是开集, 从而是可测集.
  2. 取一列分割 `Delta^((n))`, 满足 `lim_(n to oo) ||Delta^((n))|| to 0`. 根据 Darboux 定理, `bar int_a^b f(x) dx = lim_(n to oo) sum M_k^((n)) |I_k^((n))|`,
    `ul int_a^b f(x) dx = lim_(n to oo) sum m_k^((n)) |I_k^((n))|`.     现在考虑函数列 `omega_n(x) = { M_k^((n)) - m_k^((n)), x in I_k^((n)); 0, x "是" Delta^((n)) "的分点" :}` 则排除掉所有 `Delta^((n))` 的分点后, 成立 `omega_n overset"a.e." to omega`. 记 `|f| le M`, 则对每个 `n` 有 `|omega_n| le 2M`, 由控制收敛定理知 `lim_(n to oo) int_a^b omega_n(x) dx = int_a^b omega(x) dx`. 另一方面, `lim_(n to oo) int_a^b omega_n(x)` `= lim_(n to oo) sum (M_k^((n)) - m_k^((n))) |I_k^((n))|` `= bar int_a^b f(x) dx - ul int_a^b f(x) dx`.

`f` 在 `[a, b]` 上 Riemann 可积 `rArr` Lebesgue 可积, 且积分值相同.

  1. 在 `[a, b]` 上, 因为 `f` Riemann 可积, 所以它有界; 又由 Lebesgue 定理, `f` 几乎处处连续. 连续函数是可测函数, 而零测集不改变可测性, 故 `f` 是有界可测函数, `f in L([a, b])`.
  2. 任取 `[a, b]` 的分割 `Delta`, 在每个子区间 `I_k` 上有 `m_i |I_k| le int_(I_k) f(x) dx le M_i |I_k|`. 根据 Lebesgue 积分的区域可加性, 求和得到 `sum m_i |I_k| le int_a^b f(x) dx le sum M_i |I_k|`. 上式对一切分割取上、下确界, 可知 Lebesgue 积分 `int_a^b f(x) dx` 介于 Darboux 上下积分之间. 但 `f` Riemann 可积, 上下积分相等, 因此 `f` 的 Lebesgue 积分值与 Riemann 积分值相等.

积分换序的 Fubini 定理*

在 Riemann 积分理论中, 如果 `f(x, y)` 在 `I = [a, b] xx [c, d]` 上连续, 则重积分等于累次积分, 且累次积分可以换序: `int_I f(x, y) dx dy` `= int_a^b dx int_c^d f(x, y) dy` `= int_c^d dy int_a^b f(x, y) dx`. 本节建立 Lebesgue 积分换序的相关定理. 我们将看到, 在 `RR^n` 上进行积分换序几乎不需要任何特殊条件, 只需 `f in L(RR^n)` 即可. 这是 Lebesgue 积分的又一大优点.

    设 `f(x, y)` 在 `RR^n = RR^p xx RR^q` 上非负可测, 且满足

    (A) 作为 `y` 的函数, `f` 在 `RR^q` 上非负可测 (`"a.e. " x in RR^p);

    (B) 作为 `x` 的函数, `int_(RR^q) f(x, y) dy` 在 `RR^p` 上非负可测;

    (C) `f` 在 `RR^n` 上的重积分等于累次积分: `int_(RR^n) f(x, y) dx dy` `= int_(RR^p) dx int_(RR^q) f(x, y) dy`.

    以上各积分均指 Lebesgue 积分. 我们记满足 A, B, C 三个性质的非负可测函数 `f` 的全体为 `cc F`. 显然 `cc F` 非空, 且由积分的线性性有:
  1. `f in cc F, c ge 0` `rArr c f in cc F`;
  2. `f, g in cc F` `rArr f + g in cc F`;
    3. 进一步可以证明
  3. `f, g in cc F`, `f - g ge 0`, `g in L(RR^n)` `rArr f - g in cc F`;
  4. `f_k in cc F`, `f_k uarr f` `rArr f in cc F`;
  5. `f_k in cc F`, `f_k darr f`, `f_1 in L(RR^n)` `rArr f in cc F`.

    3. 的证明: 由积分的线性性, 只需证 `g` 在 `RR^n` 上几乎处处有限. 因为 `g in cc F` 且 `int_(RR^n) g lt oo`, 由性质 C 知道 `x ↦ int_(RR^q) g(x, y) dy` 在 `RR^p` 上几乎处处有限. 再由 B, `y ↦ g(x, y)` 在 `RR^q` 上几乎处处有限, `"a.e. " x in RR^p`.

    4. 的证明: (A) 非负可测函数列的极限仍然非负可测.

    (B) 由 Beppo Levi 定理 `int_(RR^q) f(x, y) dy = lim_(k to oo) int_(RR^q) f_k(x, y) dy`.

    (C) 注意 `f_k uarr f`, `(int_(RR^q) f_k(x, y) dy) uarr (int_(RR^q) f(x, y) dy)`, 用两次 Beppo Levi 定理 `int_(RR^n) f(x, y) dx dy` `= lim_(k to oo) int_(RR^n) f_k(x, y) dx dy` `= lim_(k to oo) int_(RR^p) dx int_(RR^q) f_k(x, y) dy` `= int_(RR^p) dx lim_(k to oo) int_(RR^q) f_k(x, y) dy` `= int_(RR^p) dx int_(RR^q) f(x, y) dy`.

    5. 的证明: 与 4. 类似, 但使用控制收敛定理.

    积分换序定理 仍记 `RR^n = RR^p xx RR^q`, `cc F` 的定义同上, 我们有
  1. (非负可测情形, Tonelli 定理) `RR^n` 上所有非负可测函数均属于 `cc F`.
    2. 将性质 A, B 中的“非负可测”换成“可积”, 记为 A', B', 然后记 `RR^n` 上满足 A', B', C 的可积函数全体为 `cc F'`. 则有:
  2. (可积函数情形, Fubini 定理) `RR^n` 上所有可积函数均属于 `cc F'`.
    3. 不论是 1. 还是 2. 的情形, 由 `p, q` 的任意性和 `x, y` 的对称性, 可知两个累次积分可以换序: `int_(RR^n) f(x, y) dx dy` `= int_(RR^p) dx int_(RR^q) f(x, y) dy` `= int_(RR^q) dy int_(RR^p) f(x, y) dx`. 需注意 Fubini 定理的逆不成立: 即使两个累次积分存在且相等, `f` 在 `RR^n` 上也可能是不可积的.
  1. 要证 Tonelli 定理, 根据引理的 4. 只需证 `RR^n` 上所有非负可测简单函数属于 `cc F`. 又由引理的 2. 只需证任意可测集 `E` 的特征函数 `chi_E in cc F`.
  2. 从特殊到一般, 先设 `E = I_1 xx I_2`, 其中 `I_1, I_2` 分别是 `RR^p`, `RR^q` 中的矩体. 此时显然 `chi_E in cc F`, 三个积分都等于 `|I_1| xx |I_2|`.
  3. 若 `E` 是 `RR^n` 的开集, 则 `E` 能写成可数个互不相交的半开闭矩体之并 (??): `E = uuu_(k ge 1) I_k`. 事实上记 `E_k = uuu_(i=1)^k I_i`, 则 `{E_k}` 为递增集列. 由引理的 2. 知道 `chi_(E_k) in cc F`, 又由引理的 4. 知道 `chi_E in cc F`.
  4. 若 `E` 是有界闭集, 将它写为两个有界开集的差集, 从而由引理的 3. 知道 `chi_E in cc F`.
  5. 若 `{E_k}` 为递减可测集合列, `m(E_1) lt oo`, 且 `AA k, chi_(E_k) in cc F`. 记 `E = nnn_(k ge 1) E_k`, 则由引理的 5. 知道 `chi_E in cc F`.
  6. 若 `E` 是零测集, 此时存在递减开集列 `G_k supe E` 满足 `lim_(k to oo) m(G_k) = 0`. 记 `H = nnn_(k ge 1) G_k`, 则 `chi_H in cc F`. 注意到 `E sube H`, `m(H) = 0`, 有 `int_(RR^p) dx int_(RR^q) chi_E(x, y) dy` `le int_(RR^p) dx int_(RR^q) chi_H(x, y) dy` `= int_(RR^n) chi_H(x, y) dx dy` `= 0` `= int_(RR^n) chi_E(x, y) dx dy`. 故 `chi_E` 满足条件 C. 上式还推出, `x ↦ int_(RR^q) chi_E(x, y) dy` 在 `RR^p` 上几乎处处为零, 于是对几乎处处的 `x in RR^p`, `y ↦ chi_E(x, y)` 在 `RR^q` 上几乎处处为零. 于是 `chi_E` 满足条件 A 和 B, `chi_E in cc F`.
  7. 最后, 对任意可测集 `E`, 将它写为零测集与 `F_sigma` 集的不交并: `E = Z uu K = Z uu uuu_(k ge 1) F_k`, 其中每个 `F_k` 都是有界闭集, `chi_(F_k) in cc F`. 要证 `chi_E in cc F`, 只需证 `chi_K in cc F`. 取 `A_k = uuu_(i=1)^k F_i`, 则 `{A_k}` 为递增集列, 利用引理的 2. 和 4. 就知道 `chi_K in cc F`.
  8. 再证 Fubini 定理. `f` 的正部与负部均为非负可测函数, 由 Tonelli 定理, `f^(+), f^(-)` 满足性质 A, B, C. 在 `f` 可积的假定下, 所有积分值都是有限的, 从而可以做减法运算, 立即得到定理的结论.

可积函数的连续性*

我们记 `C_0(E)` 为 `E` 上具有紧支集的连续函数的集合.

任意 `f in L(E)`, 存在 `f_k in C_0(RR^n)` 使得 `f_k overset (L^1) to f`.

上述定理的 `f_k` 可以换成具有紧支集的阶梯函数列. 阶梯函数是一类特殊的简单函数, 每块定义域 `E_i` 都是 `RR^n` 中的超立方体.

变分引理 设 `f in L(RR^n)`, 若对 `AA varphi in C_0(RR^n)` 有 `int_(RR^n) f(x) varphi(x) dx = 0`, 则 `f` 几乎处处为零.

绝对连续性 设 `f in L(E)`, 则对 `AA epsi gt 0`, `EE delta gt 0`, 使对任意满足 `m(e) lt delta` 的子集 `e` 成立 `int_e |f(x)| dx lt epsi`.

我们称一元函数 `f` 绝对连续, 如果对 `AA epsi gt 0`, `EE delta gt 0`, 使得任意长度总和小于 `delta` 的有限个区间 `[a_i, b_i]_(i=1)^n` 满足 `sum_(i=1)^n |f(a_i) - f(b_i)| lt epsi`.

平均连续性 设 `f in L(RR^n)`, 则 `f(x+h) overset (L^1) to f(x)`. 这里的平均是指“积分平均”.
